# 逐项深化框架

## 从知识到学习目标

研究建立事实底座：一句话解释内容是什么，必要背景与时间/地理范围，关键机制、对象及关系，争议或误区。将背景知识与展项中必须学会的内容分开，避免无限扩展。

判断为什么观众值得学习：它能解释生活中的什么现象、纠正什么误区、支持什么理解或选择？如客群未知，先明确合理假设。将目标写为可观察的结果，例如“能说明两种配比为何产生不同性质”，不要只写“增强认知”。

社会与精神意义应从证据和主题关系展开，如协作、技艺传承、公共责任、科学探索与人与自然的关系。解释从具体内容到意义的推导；无证据的拔高只能是策划解读，不能写成历史人物的真实动机、某群体的统一价值观或必然观众感受。

## 八个方向

| 方向 | 必须回答的具体问题 |
| --- | --- |
| 内容与背景 | 是什么、如何发生、有什么可靠证据、哪里容易讲错？ |
| 学习价值与意义 | 为什么与观众有关？社会或精神意义怎样由内容支撑？ |
| 叙事解释 | 时间轴、地图、因果链、剖面、对比、角色视角或分层信息，哪种结构最能讲清？给出关键节点或展示顺序。 |
| 呈现形式 | 从真实对象的形态、材料、动作或文化语境找形式；造型如何帮助理解，而非仅装饰？ |
| 深入浅出的体验 | 抽象概念如何转成可操控变量与可感知变化？哪些条件被简化？ |
| 参与学习 | 观众操作什么、看到什么、判断什么？失败怎样反馈、重试怎样帮助学习、完成怎样总结？ |
| 传感器与媒介 | 内容中的动作适合测量什么量？输入如何影响输出？为什么需要这种技术？ |
| 空间与展品 | 展品、观众、屏幕与投影分别在哪里？视线、尺度、动线与物理/数字边界怎样配合？ |

对有价值的方案可提供一个推荐方案和一个更简单的替代方案；不机械凑数量。画面、声音、装置造型、互动规则需具体到足以讨论，并保持概念深度，不冒充施工方案。

## 交互与工程表达

用“动作 → 输入变量 → 触发/判断 → 画面或实体反馈 → 学习结果”表达；附必要的重置、错误反馈、多人/单人关系及无法完成动作时的替代入口。观众是否学会可用一个预测、选择或复述问题检验；参与时长和教育效果未经测试不得宣称已证明。

传感器写类别和可行性条件，如旋转编码器、压力、距离、气流、视觉追踪。不要默认具体品牌、精度、阈值、尺寸或延迟。提出样机需验证的事项：噪声、光照、遮挡、误触、标定、卫生、维护或无障碍，仅写与方案相关的条件。

空间表达注明站位、观看方向、实物关系、遮挡与投影条件。效果依赖轨道定位、视差、屏幕透明性或注册对齐时要说清；概念插图和内容示意不能当作真实馆藏扫描数据。

## 用户例子的迁移方法

以下是构思示例，不能当作已验证事实或所有展项的固定答案：

- **非遗与鼓形触摸屏**：先核实该技艺与鼓的文化关系；形态用于帮助理解时再采用。若鼓只是随意借用，应寻找与内容更直接关联的对象。
- **青铜配比**：选择材料比例 → 反馈材料性质与适用器型 → 解释原因。实际冶金事实需查证，不能把所有年代或器型压成唯一“正确配方”；“生成青铜器”是教育模拟。
- **鹿哨**：气流/吹气动作 → 模拟响应 → 解释信号与动物行为。核实物种、情境及相关文化背景；提供免接触或按钮替代，画面响应不冒充真实野生动物必然反应。
- **铁路扳动或旋转**：先区分扳手、操纵杆和道岔动作；核实真实机构。测角度/位置 → 示意路线或机构变化 → 理解机械控制关系，避免借用错误动作。
- **影像延伸空间**：明确真实空间与影像透视如何衔接、观众站位及边界；不把投影概念直接等同于任意角度都成立的延伸效果。
- **滑轨屏与 X 光式效果**：位置输入 → 与展品对齐的内部结构示意 → 理解可见外形与内部关系。说明是实测影像还是重建/示意，核实结构，并测试位置同步与遮挡。
