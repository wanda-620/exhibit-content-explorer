# 文档提取与定位

## 文件口径

为每个文件分配 D01 等稳定编号，记录文件名、格式、版本信息、页数或工作表数、解析方式、扫描/OCR 情况与遗漏区域。多文件中相同名称不自动合并；先确认版本关系。

| 格式 | 定位方式 | 注意事项 |
| --- | --- | --- |
| PDF | 文件物理页序（从 1 开始）及可见印刷页码 | 如“PDF 第 18 页；印刷页 12”。封面、罗马数字和附件需区分。扫描版先 OCR，再对命中页与上下文渲染核对；跨页表格拼接但保留各页来源。 |
| Word | 固定渲染版本的页序，辅以标题与段落/表格位置 | DOCX 的段落序号、分页符或缓存分页标记不能直接证明实际页码。使用可用渲染器转 PDF 并核对；记录渲染环境或版本。字体、纸张变化可能改变分页。无法渲染时注明“页码待核验”，仍提供标题、段落及表格行定位。 |
| Excel | 工作表名、单元格范围；有固定打印版时补充打印页 | 工作表序号或行号不是页码。核查打印区域、缩放、纸张、分页与重复标题；必要时固定导出 PDF 并标注导出页序。没有固定打印版就明确“无固定页码”，不伪造页数。读取单元格原值/显示值、合并单元格、批注、隐藏区域及相关对象；不能读取的区域列入缺口。 |

如用户必须拿到真实页码而当前工具无法分页，说明需要哪种固定版文件或渲染条件；先完成可定位的部分。旧版 .doc/.xls 需合适解析器或保留原件的格式转换；不能当成 .docx/.xlsx 直接解析。

## 从命中恢复完整项

1. 按文件顺序检索八个指定关键词，记录每次命中的页/单元格、关键词和上下文。不要只读取搜索工具返回的短片段。
2. 用展项编号、同级标题或表格列确定所属项与边界。同一项多次命中合并为一个稳定 E001 编号，列出全部命中位置；不同项标题相同也保留独立编号。
3. 从项的开始读到下一同级项之前，追踪续表、跨页段落和指向脚本/附录的引用。将不同位置的原文分别附上出处；不要把没有读到的附录写成已提取。
4. 保留完整相关文字、子项顺序、数字单位、表格列关系与注释。无法辨认字符标记“[辨识不清]”。可以整理版式，不改写原文事实。摘要另列。
5. 全文语义复核可补充“数字展项、沉浸式、触摸屏、投影、体感、游戏、知识延伸”等表达；这不是八个关键词的替代，也不是要求所有文件必有此类项。
6. 建立命中覆盖账本：每次命中 → 展项 ID / 合并依据 / 排除理由。目录与正文重复、页眉模板、行政管理语境的“重点”等可合理排除；项目级说明若影响展项，单列为统筹内容，不能悄悄丢弃。

## 完整性与状态

报告已扫描的页数/工作表范围、直接命中数、语义补充数、独立项数、排除数，以及读取失败区域。计数来自实际扫描记录，不能估算。

长文档按稳定 ID 分批处理，维护“已提取 / 已核对定位 / 已研究 / 已深化 / 待补材料”状态。全部提取后再研究，便于用户确认遗漏；无需逐批等待批准。被截断的输出应明确下一批起点，最终对照总清单收尾。未读取或未研究项必须可见。
