# 输出模板

依据实际材料填写，不用虚构示例值补齐空字段。未知写原因与下一步核实方式。可按交付格式调整排版，但保留出处、完整原文和处理状态。

## A. 文档说明与覆盖

文件 ID / 文件名 / 版本；读取与 OCR 范围；总页数或工作表数；页码口径；完整性缺口；直接命中、语义补充、排除与独立项的实际数量；各批完成范围。

## B. 总清单

| ID | 原文名称及层级 | 命中词/语义补充 | 原文定位 | 内容摘要 | 处理状态 |

总清单用于浏览，不替代下方逐项完整原文。项目级要求、排除记录及待读取区域另列。

## C. 每项内容卡

### E___ 原文名称

**原文依据**

- 文件 ID；标题层级；页码范围与口径；段落、表格或单元格位置。
- 完整相关原文：按原顺序保留所有子项；各跨页片段或表格分别定位。图片/示意图附可读描述与出处，并注明是否实际查看。
- 命中关键词及其位置；合并关系或语义补充理由。

**事实研究**

- 研究模式：R0 无外部检索 / R1 快速核验 / R2 深度研究 / R3 文献综述；选择原因、检索范围与截止日期。
- 是什么、背景、机制、关键事实与易误解之处。
- 原文与核查结果的差异；已核实/待核实结论。
- 来源编号、机构、标题、链接、相关章节/页码与访问日期；明确各来源支持哪条结论。来源没有页码就用章节或段落，不编造页码。
- R2 列出研究子问题、已确认、分歧、未知与停止条件；R3 附证据表，并按主题写共识、分歧、证据质量和空白。R0/R1 不机械套用这些栏目。
- 研究结论改变了哪个内容、叙事或互动判断；没有改变的背景资料移到来源索引。

**学习价值与意义〔策划解读〕**

- 目标客群及假设；可观察的学习目标。
- 与观众的关联；社会和精神意义及其推导依据。

**深化诊断**

- 内容内核：“观众应理解……，因为……”。
- 参观前 → 参观后的认知或能力变化；可观察的成功迹象。
- 当前深化层级（L1–L7）及依据；下一层需要解决的核心问题。
- 已确定 / 当前假设 / 待选择 / 待验证。

**路径发散与选择〔创意建议〕**

开放型展项给出 2–3 个体验逻辑不同的方向；方向已经明确时说明为何直接深化。每个方向包含一句话概念、学习机制、观众旅程、媒介、空间条件与风险。用内容准确度、学习清晰度、动作贴合度、媒介必要性、空间融合度、可进入性和可实施性作高 / 中 / 低比较，并给出推荐理由。

**讲述与呈现〔创意建议〕**

- 核心信息；推荐叙事结构及具体顺序。
- 推荐装置/媒介与内容的关联；体验中哪些事实被简化。
- 动作 → 输入变量 → 判断 → 反馈 → 学习结果；错误、重试、结束与替代入口。
- 传感器类别、空间与展品关系；适用条件、待验证问题。
- 必要时列简单替代方案及取舍；不适用维度注明原因。

**核实与落地条件**

待补资料、工程验证、空间/预算/客群假设；一项能检查学习目标的问题或小任务。明确这是概念建议、已有依据还是实测结果。列出能够降低最大风险的最小下一步，避免只写“继续优化”。

## D. 全局收尾

列出共享叙事和跨项联动（如有）、命中覆盖账本、来源索引、尚未完成的 ID 与原因。候选创意不能反向混入原文提取清单。
