# 展项深化工作法

这套流程把开放式 brainstorm 转成可追踪的展项设计判断。目标不是产出最多点子，而是让使用者看清：内容为什么值得讲、观众应发生什么变化、哪种体验最能促成这种变化，以及下一步如何验证。

## 选择工作路径

根据材料成熟度选最轻但足够的路径，中途发现关键缺口时可升级：

| 路径 | 适用情况 | 过程 | 交付 |
| --- | --- | --- | --- |
| 直接深化 | 原文、客群和目标已明确，用户需要快速形成方案 | 回写理解 → 形成内容内核 → 给出推荐方案 → 自检 | 一张完整深化卡 |
| 引导澄清 | 内容明确，但客群、学习目标或空间条件会改变方案 | 利用已有信息；一次询问一个最高影响问题 → 回写理解 → 深化 | 经确认的深化卡和假设清单 |
| 多方案比较 | 方向开放、利益相关者需要选择，或不同媒介各有合理性 | 回写理解 → 2–3 个不同体验逻辑 → 比较取舍 → 推荐 → 深化 | 路径比较表、推荐方案及替代方案 |

多展项任务先做全量提取和轻量诊断，再逐项深化。为每项标明状态，防止前几项写得很深、后续项被省略。可以识别共享媒体系统和空间联动，但每项保留自己的内容内核与学习目标。

## 第一步：形成共同理解

在提出形式前，用五行以内回写：

1. **原文要讲什么**：只写原文能支持的核心内容。
2. **内容内核**：用“观众应理解……，因为……”表达。
3. **目标观众与变化**：参观前可能怎样理解，参观后应能解释、判断或完成什么。
4. **约束**：空间、展品、时长、客流、预算、技术或维护条件；未知就标假设。
5. **成功迹象**：一个能观察或询问的学习证据。

不要询问文档和上下文已经回答的问题。缺失信息不会改变当前概念时，采用明确假设继续。确实需要用户判断时，一次只问一个高影响问题，并给出推荐选项或具体判断依据；得到足够信息后停止提问。

## 第二步：诊断当前深化层级

层级表示方案下一步应补什么，不是给创意打分：

| 层级 | 已经具备 | 下一步深化 |
| --- | --- | --- |
| L1 事实 | 有主题、对象或事件 | 核实背景、机制、边界和误区 |
| L2 解释 | 有事实和说明 | 建立时间、因果、比较或结构关系 |
| L3 学习 | 有叙事内容 | 明确观众为何学习及可观察的学习目标 |
| L4 参与 | 有观看或操作设想 | 建立动作—判断—反馈—结论闭环 |
| L5 媒介 | 已有交互闭环 | 选择真正必要的传感器、影像、声音或实体装置 |
| L6 空间 | 已有单体展项概念 | 处理站位、动线、展品关系、多人使用和环境延伸 |
| L7 验证 | 方案基本完整 | 设计内容核查、交互样机、空间测试与学习验证 |

不要把“用了更多技术”当成层级更深。若 L2、L3 尚不清楚，应先补叙事和学习逻辑，而不是直接增加声光电。

## 第三步：生成真正不同的路径

以内容内核为锚点，从适合该内容的体验语法中选 2–3 种，不必每次覆盖全部：

- **关系叙事**：时间轴、地图、因果链、对比、分层剖面；适合过程复杂、易混淆的内容。
- **对象与动作**：利用真实器物的形态、材料、手势、工具或工序；适合具身技艺和机械机制。
- **变量实验**：观众改变一个或多个变量，观察结果；适合材料配比、生态关系、工程参数和科学机制。
- **角色决策**：在真实约束下选择并承担反馈；适合历史抉择、公共议题和资源配置。
- **空间感知**：影像、声音或灯光与位置、尺度和展品产生关系；适合环境、迁徙、遗址和不可见结构。
- **共同参与**：多人协作、比较或累积形成结果；仅在“共同完成”本身有内容意义时采用。

每条路径至少说清：一句话概念、关键学习机制、观众旅程、核心媒介、空间条件、主要风险。路径差异应体现在“观众怎样理解”，而不是视觉皮肤或设备清单。

## 第四步：比较并推荐

使用高 / 中 / 低加简短依据，避免没有证据的精确分数：

| 判断维度 | 要问的问题 |
| --- | --- |
| 内容准确度 | 是否尊重事实边界，能否处理误区和不确定性？ |
| 学习清晰度 | 观众做完后能否说出或判断核心内容？ |
| 动作贴合度 | 操作是否源于内容中的真实动作、关系或变化？ |
| 媒介必要性 | 去掉这项技术后，理解是否明显变差？ |
| 空间融合度 | 是否与展品、尺度、动线和观看关系互相支持？ |
| 可进入性 | 儿童、老人、轮椅使用者、听视障观众是否有替代入口？ |
| 可实施性 | 是否能在客流、维护、卫生、光声环境和预算假设下运行？ |

先给推荐结论，再解释关键取舍。推荐方案可以吸收另一方向的一个优点，但不要拼成失去重点的“大而全”。保留一个简化替代方案，说明降低了什么成本，也损失了什么学习效果。

## 第五步：把方向深化成可讨论方案

按以下链条描述，确保每一环都能追溯到前一环：

**事实依据 → 内容内核 → 学习目标 → 观众动作 → 系统判断 → 反馈 → 所学结论 → 社会/精神意义 → 媒介与空间 → 验证方法**

补充一条参观旅程：吸引注意、理解规则、首次行动、反馈与修正、完成、带走的结论。说明等待、误操作、未完成、多人争抢和无障碍替代如何处理。造型和视觉语言要说明如何帮助理解；仅有气氛价值时直说，不把装饰包装成学习机制。

## 第六步：自检与下一步

交付前回答：

- 去掉屏幕、传感器或沉浸效果后，哪一条理解会丢失？如果没有，技术可能不是必要条件。
- 观众的动作与内容中的真实动作或关系是否一致？若是比喻，是否会造成错误理解？
- 观众完成后能否用一句话说出所学结论？反馈是否只在奖励操作熟练度？
- 社会与精神意义是否从具体事实推导，还是空泛口号？
- 哪个判断仍是假设？要用资料核查、纸面流程、低保真交互还是现场样机验证？

最后列出“已确定 / 当前假设 / 待选择 / 待验证”，以及最小下一步。最小下一步应能降低最大的内容或体验风险，例如核查一条史实、用纸面卡测试因果顺序、用位置跟踪样机验证滑轨对齐，而不是笼统写“继续优化”。
